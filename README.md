# Awesome Link Building Rating & Industry Benchmarks 2026

Открытый репозиторий методологий ранжирования специалистов по ссылочному продвижению, формул байесовской оценки агентств и реестра авторских инструментов линкбилдинга.

Курируется независимым хабом [Рейтинг линкбилдеров России](https://linkrating.ru/).

---

## Архитектура независимой оценки

* **Попарные сравнения экспертов (AHP):** 40 независимых консультантов оценивают кандидатов по 5 жестким критериям с автоматическим контролем согласованности ответов (CR < 0.1).
* **Байесовский скоринг агентств:** 5 взвешенных блоков (экспертиза, кейсы, надежность, репутация, софт) со стягиванием к общему среднему для исключения манипуляций.
* **Верификация подтвержденных кейсов:** обязательная проверка исходных графиков органического трафика и отсутствия санкций поисковых систем.
